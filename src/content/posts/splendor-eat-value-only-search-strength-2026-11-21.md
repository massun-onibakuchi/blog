SplendorのAIでは、ニューラルネットが「どの手を読むか」（方策）と「読んだ先が有利か」（価値）を予測し、PUCT探索に渡す。価値の予測誤差を減らせても、実戦で強くなるとは限らない。どちらの改善が探索の勝敗に効いているのか、切り分けたかった。

Attention型モデルEATの同じ約970万局面から、価値が合法手の表現も読む「pool」と、候補ごとの評価を混ぜる「pairq」を学習した。前者は候補表現を方策確率で加重平均し、従来の局面表現に加えて価値を出す。方策と価値を個別に差し替え、同じ学習seedの基準モデルを相手に512回のPUCTで先後交換対局をした。

| EATの変更（基準モデルとの対局） | 得点率［95%区間］ |
| --- | ---: |
| 方策固定・価値をpoolに | 53.4%［51.2–55.5］ |
| 方策固定・価値をpairqに | 53.1%［51.0–55.3］ |
| 価値固定・方策をpairqに | 50.9%［48.7–53.0］ |
| ４層化したモデル全体 | 50.0%［47.8–52.1］ |
| poolモデル全体 | 53.3%［51.1–55.5］ |
| pairqモデル全体 | 54.5%［52.4–56.7］ |

各条件1,024ペア、学習seedは２つ。価値だけの差し替えで両seedとも勝ち越したが、方策だけでは差を検出できなかった。層を増やすだけでも伸びない。探索が有望な枝を読む段階では、そこから持ち帰る価値の質が強さを左右していた。

pairqは予測損失が最も小さいものの、poolを直接対戦で上回るとは言えない。L4ホストCPUの単件推論費用は基準比でpoolが1.06倍、pairqが1.48倍なので、現時点の次期候補はpoolにした。さらに探索後のルート価値は、同じ探索付き対局の勝敗を通常の価値ヘッドより約23mnat（対数損失、低いほど良い）正確に予測していた。この値を価値の教師に使えば、推論を重くせずに強くできるかもしれない。

ただし比較は同系統の教師で学んだモデル間のもので、実時間を揃えた本番採用試験ではない。探索値を学習させた効果もまだ測っていない。
