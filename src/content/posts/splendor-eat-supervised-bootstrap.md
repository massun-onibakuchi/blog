自己対局による強化学習ループの初期モデル（ブートストラップ）として用いるため、パラメータ数888,324の EAT アーキテクチャに対し、深さ3の探索を行うルールベース教師AIのソフト方策および最終勝敗結果（WDL）を用いた教師あり学習を実施した。

## データセット構成と学習設定

| 項目 | 設定値 |
| --- | ---: |
| 訓練データ行数 | 1,048,576 |
| 検証データ行数 | 131,072 |
| テストデータ行数 | 131,072 |
| 学習エポック数 | 8 |
| オプティマイザ更新ステップ | 8,192 |
| バッチサイズ | 1,024 |
| A100での学習所要時間 | 約407秒 |

テストデータセットはチェックポイント選定には一切使用せず、学習完了後に汎化性能を検証する目的で1回のみ評価した。

## 未知データ（holdout）でも安定した汎化を維持

| 評価指標 | 訓練データ | 検証データ | テストデータ |
| --- | ---: | ---: | ---: |
| Policy KL | 0.1767 | 0.1790 | 0.1803 |
| 教師Top-1一致率 | 0.7243 | 0.7236 | 0.7221 |
| WDL クロスエントロピー | 0.5780 | 0.5932 | 0.5729 |
| WDL ブライアスコア | 0.3820 | 0.3896 | 0.3780 |

局面評価（value）の予測精度は、局面情報を参照せず出現頻度のみを出力するベースライン（class-frequency baseline）を明確に上回った。

| テストセット評価指標 | 頻度ベースライン | EAT |
| --- | ---: | ---: |
| WDL クロスエントロピー | 0.7265 | 0.5729 |
| WDL ブライアスコア | 0.5061 | 0.3780 |

勝敗予測のキャリブレーション誤差も最大で約0.03に収まっていた。

## ゲーム序盤の局面評価には課題が残る

対局の進行度合い（手数帯）ごとに精度を分解したところ、明確な性能差が確認された。

| 手数帯（decision band） | WDL ブライアスコア | 教師Top-1一致率 |
| --- | ---: | ---: |
| 0〜5手 | 0.5046 | — |
| 0〜11手 | — | 0.495 |
| 46〜73手 | 0.226 | 0.875 |

序盤局面における価値予測のブライアスコアは、同手数帯における頻度ベースライン（0.5060）と大差がなかった。これについては、ゲーム序盤は勝敗を決定づける確定情報が本質的に乏しいことと、モデルが微弱なシグナルを捉えきれていないことの双方が考えられる。

検証データにおける結合損失（joint loss）は、第1エポックの1.6410から第8エポックの1.4491まで一貫して減少し続けたため、最終チェックポイントを採用した。より多くの学習ステップを割り振る余地も残されている。

今回の実験では、初期モデルとして方策と局面評価を同時に学習可能であることの確認にとどまっており、実対局（arena）における強さはまだ測定していない。次の段階として、このチェックポイントにPUCT探索を組み合わせ、方策単体よりも優れた着手判断を生成できるかを検証していく。
