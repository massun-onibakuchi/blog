[前回の記事](/posts/splendor-ppo-policy-fragmentation-and-loops-2026-11-04)で、確実に勝てる局面でトークン操作を選び引き分けに至る事例を調べた。方策確率の分散を抑えるだけでなく、評価ネットワークから独立した確定勝利の判定器を探索に組み込めないかと考えた。

Splendorは15点到達後も同一ラウンド終了まで相手に手番が残り、同点時は購入カード数の少なさで勝敗が決まる。相手のキープカードや山札といった不完全情報もある。そこで、相手の全応手と整合する隠れ状態に対し、指定手番（H手）以内に必ず勝てる手順を判定する、有界なdf-pn（深さ優先証明数探索）を実装した。コスト下界に基づく威信点上限（prestige envelope）で目標点に届かない枝を刈り、これをPUCTの根ノードに接続した。確定勝利が証明された手を無条件で選び、相手の確定勝利を許す手を候補から除外する。

RKL0@256モデルを用い、初期配置を揃えた600ペア（1,200局）で検証した。対局中の意思決定を外部監査（H=4、40万ノード）で評価した結果を示す。

| 指標 | 通常のPUCT（証明なし） | 勝利証明つきPUCT（緩和下界） | 勝利証明つきPUCT（全下界＋最悪ドロー） |
| --- | ---: | ---: | ---: |
| 4手以内の確定勝利を見送った手 / 該当局面 | 126 / 1,027（12.3%） | 13 / 1,092（1.2%） | 11 / 1,091（1.0%） |
| 相手の必勝を許す手を選んだ回数（代替手あり） | 129 | 57 | 46 |
| 対局スコア（対通常PUCT） | — | 0.528 ± 0.015 | 0.528 ± 0.015 |
| 終盤1手あたりの意思決定時間 | 89 ms | 87 ms | 87 ms |

証明の導入により、確定勝利の見逃しは12.3%から1.2%へ減少し、相手に必勝を許す着手も129回から57回へ半減した。意思決定時間は平均87ミリ秒と、証明なしの89ミリ秒と同等である。一方、木の内部まで証明を広げると処理時間が64%増加したため、根ノードへの適用に限定した。

次に、探索の枝刈りをさらに早めるため、従来の緩和下界（$h_{\text{res}}$）に加え、手持ち上限10枚による購入遅延（$h_{\text{cap}}$）と各色の供給上限（$h_n$）を導出して組み込んだ。3割以上のカードで購入下界が厳格化したものの、探索ノード数の削減幅は0.1%未満にとどまり、判定が不明から解決へ移行する局面も現れなかった。

調べると、威信点上限が山札の未知カードを過度に楽観視していた。未知カードの中に都合よく高得点・低コストのカードが存在すると仮定されるため、公開カードの下界を厳しくしても、仮想的な山札のカードによって上限値が維持されていた。

必勝証明である以上、山札から補充されるカードのあらゆる組み合わせに対しても勝てなければならない。締め切りまでにめくられる未知カードは1手番あたり最大1枚であり、最悪の条件では無用なカードから順に出現する。そこで、各ランクで利用可能な未知カードの枚数に上限を設ける最悪ドロー下界（$+\text{draws}$）を導入した。

![探索地平線ごとの生成ノード数比較と、実戦根局面クエリ（9,874手）における総探索ノード数。保持上限や供給上限の厳格化ではノード数がほぼ変化しないのに対し、最悪ドロー下界の導入によってノード数が約29%削減されている。](/images/posts/splendor-sure-win-proofs/bounds-ablation.svg)

| 地平線 H | 緩和下界（$h_{\text{res}}$） | 保持・供給下界（$+h_{\text{cap}}+h_n$） | 最悪ドロー下界（$+\text{draws}$） | 全条件適用（all） |
| --- | ---: | ---: | ---: | ---: |
| 3（探索ノード数 / 1手時間） | 531 / 0.97 ms | 531 / 0.95 ms | 414 / 0.78 ms | 414 / 0.79 ms |
| 4（探索ノード数 / 1手時間） | 2,637 / 2.90 ms | 2,637 / 2.93 ms | 2,463 / 2.65 ms | 2,463 / 2.65 ms |
| 5（探索ノード数 / 1手時間） | 8,284 / 12.9 ms | 8,280 / 12.9 ms | 5,969 / 8.6 ms | 5,940 / 8.5 ms |
| 6（探索ノード数 / 1手時間） | 21,250 / 32.4 ms | 21,231 / 32.1 ms | 17,644 / 25.0 ms | 17,581 / 25.4 ms |

この制約により、実戦の根局面クエリ9,874手において探索ノード数が29%削減され、計算予算上限で不明だった237局面のうち46局面が新たに解決した。対局でも相手に必勝を許す着手が57回から46回へ一段と減少した。

不完全情報ゲームの証明探索において、公開情報の精密な下界よりも、未知情報に対する最悪ケースの評価が枝刈りの効率を決定づける点が明確になった。なお、供給下界の計算は素朴に実装するとXeon上で12%の計算時間増加を招いたが、局面ごとの事前計算で解消した。確定勝利の保証は、勝率そのものを大きく引き上げるわけではないが、終盤の致命的な失策を排除するうえで堅牢に機能している。
